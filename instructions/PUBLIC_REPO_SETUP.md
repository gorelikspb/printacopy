# Настройка публичного репозитория

## ⚠️ Важно: Защита приватных файлов

При работе с публичным репозиторием нужно убедиться, что приватные файлы не попадают в Git.

## 📋 Файлы, которые НЕ должны быть в публичном репо:

1. **`instructions/`** - приватные инструкции
2. **`screenshots/`** - скриншоты (опционально, можно оставить)
3. Другие приватные файлы

## ✅ Настройка перед публикацией:

### 1. Проверьте .gitignore

Убедитесь, что в `.gitignore` есть:
```
instructions/
```

### 2. Удалите из Git (если уже закоммичены):

```bash
git rm -r --cached instructions/
git commit -m "Remove instructions/ from repository"
```

### 3. Используйте pre-push проверку

**Windows:**
```powershell
.\pre-push-check.ps1
```

**Linux/Mac:**
```bash
./pre-push-check.sh
```

### 4. Настройте Git hook (опционально):

Автоматическая проверка перед каждым push:

**Windows:**
```powershell
Copy-Item pre-push-check.ps1 .git\hooks\pre-push
```

**Linux/Mac:**
```bash
cp pre-push-check.sh .git/hooks/pre-push
chmod +x .git/hooks/pre-push
```

## 🔄 Процесс работы:

1. **Разработка** - работаете с инструкциями локально
2. **Перед push** - запускаете проверку
3. **Если репо публичный** - проверка не даст запушить `instructions/`
4. **Если репо приватный** - проверка пропустит (можно пушить все)

## 📦 Архив инструкций:

Храните `instructions.zip` отдельно и распаковывайте в новые проекты.

---

**Помните**: Всегда проверяйте, что приватные файлы не попадают в публичный репозиторий!
